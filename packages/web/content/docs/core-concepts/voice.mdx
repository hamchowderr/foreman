---
title: Voice I/O
description: Talk to Foreman and have it talk back.
---

Foreman supports voice input across its chat channels and the web UI. Hit
the mic icon and speak your request — your audio is transcribed and sent
as a normal text message.

## Providers

| Direction | Web UI | Channels (Telegram, etc.) |
| --- | --- | --- |
| **Speech → text** | Web Speech API (browser, no server call) | OpenAI Whisper |

The web mic button uses the browser's built-in Web Speech API
(`packages/web/src/components/chat/multimodal/mic-button.tsx`) — no audio
ever leaves the device. Channel adapters that ship audio (e.g. Telegram
voice notes) upload it to the agent server, which calls Whisper.

## Endpoint

- `POST /voice/transcribe` — multipart audio upload, returns transcribed
  text. Hard-capped at 25MB (Whisper's limit).

<Callout>
  This endpoint obeys the user's `voice` capability flag. If voice is
  disabled, it returns 403.
</Callout>

## Configuration

| Env var | Default | Description |
| --- | --- | --- |
| `OPENAI_API_KEY` | — | Whisper STT for channel-uploaded audio. |

## Self-host

Voice works identically on self-host. The browser mic button needs no
configuration — it runs entirely client-side. Channel-side transcription
just needs `OPENAI_API_KEY` for Whisper.
