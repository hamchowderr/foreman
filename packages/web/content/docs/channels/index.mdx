Foreman is the same assistant everywhere you use it. Ask in Slack, follow up
from Telegram, approve from your phone — your apps, preferences, and action
history travel with you.

## Available now

| Channel | How to use it |
| --- | --- |
| **Web** | [foreman.otakusolutions.io](https://foreman.otakusolutions.io) |
| **Slack** | DM the bot or `@mention` in a channel |
| **Discord** | DM the bot or mention it in a server |
| **Telegram** | Message `@foreman_bot` |
| **Google Chat** | Add the Foreman app in your workspace |
| **GitHub** | Tag `@foreman` in an issue or PR |
| **Linear** | Mention `@foreman` in a ticket comment |
| **MCP** | Point Claude Code, ChatGPT, or another MCP client at the Foreman endpoint |
| **A2A** | Call the Foreman A2A endpoint from another agent |
