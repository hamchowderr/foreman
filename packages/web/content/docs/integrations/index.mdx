---

Foreman is already in your chat apps. These pages are for everything else —
AI clients (via MCP), other agents (via A2A), and the differences when
you're using cloud versus self-host.

<Cards>
  <Card title="MCP (cloud)" href="/docs/integrations/mcp-cloud" description="Claude Code, ChatGPT, or any MCP client talking to cloud Foreman." />
  <Card title="MCP (self-hosted)" href="/docs/integrations/mcp-self-hosted" description="Same, but pointing at your own instance." />
  <Card title="A2A (cloud)" href="/docs/integrations/a2a-cloud" description="Call Foreman from another Mastra agent over HTTP." />
  <Card title="A2A (self-hosted)" href="/docs/integrations/a2a-self-hosted" description="Same endpoint, your own URL." />
</Cards>

<Callout type="info">
  The chat-app side of "integrations" is covered under
  [Channels](/docs/channels) — Slack, Discord, Telegram and so on are
  installed as bots/apps, not as API consumers.
</Callout>
